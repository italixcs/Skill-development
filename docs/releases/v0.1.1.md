# Skill Development v0.1.1 — reusable skill development workflow

Skill Development is an instruction-only workflow for creating, improving, evaluating, maintaining, and preparing AI agent skills for release. It keeps reusable development rules in one place and routes work to existing tools.

## Included

- A compact entry point with conditional references for scope, architecture, evaluation, security, compatibility, and publication.
- A bundled, versioned Skill Bench workflow for two independent workers and a blind reviewer, without mandatory datasets or a benchmark service.
- Integration rules for NVIDIA SkillSpector and optional Repo Cleaner, with clear private/public and publication-authorization boundaries.
- Examples, installation guidance, a banner, and a real prompt comparison with both complete task requests.
- A privacy refinement requiring sensitive values to be suppressed or redacted before inspection output is shown.

## Install and use

Obtain the source and install the complete `skill-development/` folder, including its references and license. [Installation and host-specific paths](https://github.com/italixcs/Skill-development/blob/main/docs/installation.md).

For an agent with local file access:

```text
Read skill-development/SKILL.md and follow its relevant references.
Help me develop a private skill for reviewing release notes.
Research existing options, agree on the scope, and keep changes local.
```

The package does not install tools. Paired evaluation needs independent agents; scanning needs separately installed SkillSpector. Missing required capabilities remain reported blockers for their dependent steps.

## Evidence and limits

A 54-word request plus the stored workflow and a 309-word manual brief produced functionally comparable results in one blind-reviewed Project Memory task pair. This demonstrates one prompt-reuse example, not general output-quality improvement, fewer total model tokens, or measured human time savings. The study used v0.1.0; the subsequent privacy refinement received a focused check. [Exact prompts and study limits](https://github.com/italixcs/Skill-development/blob/main/docs/examples/prompt-comparison.md).

Structural validation and installation-copy checks passed. The complete 10-file v0.1.1 package matches its recorded SkillSpector 2.12.0 static scan. One LOW prohibition-pattern match remains, triaged as a false positive without suppression. No semantic or runtime-containment analysis ran. A completed scan is not proof of safety. [Security scope and file hashes](https://github.com/italixcs/Skill-development/blob/main/docs/security.md).

Instruction reading was exercised explicitly. Codex and Claude Code copy routes are documentation-checked and locally copy-tested; native discovery and full client workflows remain unverified. The desktop public-skill exercise is deferred. This release claims a usable early workflow within those limits. [Validation record](https://github.com/italixcs/Skill-development/blob/main/docs/validation.md).
